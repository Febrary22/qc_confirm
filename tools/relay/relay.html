환영해요, 님 👋

Relay는 사내망에서 막힌 Slack 대신 쓰는 팀 채널이에요. 아래 카드대로 따라 하면 바로 쓸 수 있어요.

채팅

팀원들과 실시간으로 대화해요. /ask 질문을 쓰면 Claude가 그 자리에서 답하고, /github 요청을 쓰면 GitHub 작업 목록에 올라가 담당 세션이 확인 후 처리해요.

보드

팀이 함께 챙기는 할 일 목록이에요. 누구나 항목을 추가하고, 체크하고, 연필 아이콘으로 내용을 고칠 수 있어요.

달력

날짜를 클릭해서 일정을 남겨요. 종료일을 함께 고르면 며칠씩 이어지는 기간 일정이 색깔 띠로 표시되고, 색상도 골라 구분할 수 있어요. 이미 만든 일정도 목록에서 연필 아이콘으로 언제든 고칠 수 있어요.

팀원 현황

왼쪽 사이드바에서 지금 접속 중인 팀원과 오프라인인 팀원을 볼 수 있어요. 이름 옆 💬 버튼을 누르면 그 팀원과 1:1로 대화할 수 있어요 (완전한 비공개 DM은 아니고, 팀 내부에서 공유되는 대화예요).

/ask 질문은 Claude가 즉시 답하고, /github 요청은 GitHub 작업 목록에 올라가 담당 세션이 확인 후 처리해요 (몇 분 정도 걸릴 수 있어요).

# 샘플 파일

QC 도구를 처음 실행해볼 때 바로 업로드해볼 수 있는 예시 데이터입니다. 모두 실습용으로 생성한 가상 데이터입니다.

| 파일 | 설명 | 예상 결과 |
| --- | --- | --- |
| `sample_temperature_humidity.nc` | 기온(temperature)/습도(rh) 격자 데이터. 약간의 결측치, 이상값 1개, 시간 구간 누락 1곳 포함 | 점수 80점대 (양호) |
| `sample_sst_low_quality.nc` | 해수면온도(sst) 데이터. 전역 속성/단위 등 메타데이터가 거의 없고 결측·이상값 비중이 높음 | 점수 30점대 (불량) |
| `sample_station_readings.csv` | 관측소 시계열 CSV (temperature/humidity/pressure). 결측치, 범위 초과값, 중복 행 포함 | 점수 80점대 (양호, 경고 다수) |

세 파일을 한 번에 업로드하면 배치 비교 테이블에서 점수 차이를 바로 확인할 수 있습니다.

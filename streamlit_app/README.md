# 업무 자동화 올인원 웹앱

사내 팀원들과 함께 쓰는 사무용 파일 자동화 도구 모음입니다. PDF·엑셀 파일을
브라우저에서 올리기만 하면 병합, 분할, 순서 변경 같은 반복 작업을 몇 번의
클릭으로 끝낼 수 있어요.

## 화면 구성

- **처음 들어오면** 어떤 기능이 있고 어떻게 쓰는지 소개하는 홈 화면이 나와요.
- 왼쪽 사이드바 맨 위 **🏠 홈으로 돌아가기** 버튼으로 언제든 이 소개 화면으로 돌아올 수 있어요.
- **📡 Relay** 버튼을 누르면 팀 채팅·할일 보드·공유 달력 기능이 있는 사내 협업 도구(Relay,
  별도 아티팩트)로 새 탭에서 이동해요.
- 그 아래 검색창: 도구 이름이나 설명으로 바로 찾을 수 있어요.
- 카테고리(PDF / Excel / 한글 / NC데이터 / 기타)를 고르면 그 안에 있는 도구 목록이 나타나요.
- 사이드바 아래쪽 **✉️ 문의 및 기능 추가 요청하기** 버튼을 누르면 담당자 이메일로
  문의·요청하는 방법을 안내해줘요.
- **📋 게시판** 버튼을 누르면 자유게시판 · 문의게시판 · 아이디어게시판에서 글과 사진을
  자유롭게 올리고 댓글을 달 수 있어요. (DB 연결 방법은 아래 '게시판 데이터베이스 연결' 참고)
- 모든 도구는 **① 파일 올리기 → ② 옵션 선택 → ③ 실행 버튼 → ④ 결과 다운로드**
  순서로 똑같이 동작해요.

## 현재 제공하는 도구

**PDF**
- PDF 합치기
- PDF 분할하기 (페이지 범위 지정)
- PDF 페이지 순서 바꾸기
- PDF 페이지 삭제·추출

**Excel**
- 엑셀 합치기 (시트별 유지 / 표 하나로 합치기)
- 엑셀 시트 순서 바꾸기
- 엑셀 시트 이름 일괄 변경

**한글**
- 한글 파일 텍스트 꺼내기 (.hwp, .hwpx → 본문 글자를 뽑아 화면에 보여주고 .txt로 다운로드.
  hwpx는 본문 전체, 예전 방식인 hwp는 문서에 저장된 미리보기 글자만 지원)

**NC데이터**
- NC 파일 열어보기 (변수·차원·전역 속성 확인, 값 미리보기 표/그래프/히트맵, CSV·PNG 내려받기)
- NC/CSV 데이터 품질 확인하기 (같은 저장소의 별도 QC 도구 서비스로 이동하는 안내 화면 —
  결측치·시간연속성·값의 범위·이상치·메타데이터·중복 6가지를 점검해 0~100점으로 알려줌)

**기타**
- 폴더 용량 살펴보기 (폴더를 zip으로 올리면 안의 파일·용량 구성을 확인하고 엑셀로 정리.
  웹은 200MB 업로드 제한이 있어서, 훨씬 큰 폴더용으로 쓸 수 있는 데스크톱 버전 프로그램도
  화면 안에서 함께 내려받을 수 있음)

## 로컬에서 실행하는 방법

```bash
# 1) (최초 1회) 이 폴더로 이동
cd streamlit_app

# 2) (최초 1회, 선택) 가상환경 만들기
python -m venv .venv
source .venv/bin/activate   # Windows는 .venv\Scripts\activate

# 3) (최초 1회) 필요한 패키지 설치
pip install -r requirements.txt

# 4) 앱 실행
streamlit run app.py
```

실행 후 터미널에 나오는 주소(기본값 http://localhost:8501)를 브라우저에서
열면 됩니다. 같은 사무실 안에서 팀원과 함께 쓰려면 `streamlit run app.py
--server.address 0.0.0.0` 으로 실행한 뒤, 실행한 PC의 사내망 IP 주소로
접속하면 됩니다.

## 게시판 데이터베이스 연결

게시판은 글·사진을 계속 저장해야 해서 Postgres 데이터베이스가 필요해요. 환경변수
`DATABASE_URL`이 없으면 게시판 화면에서 "저장소가 연결되지 않았어요" 안내만 보여주고
오류 없이 넘어가요.

- **Render 배포**: 저장소 루트의 `render.yaml`에 `office-tools-db`라는 Postgres
  데이터베이스가 정의돼 있어요. Render 대시보드에서 Blueprint를 Apply하면 함께
  만들어지고, `office-tools-streamlit` 서비스에 `DATABASE_URL`로 자동 연결돼요.
  **유료 플랜(카드 등록 필요)** 이니 비용을 확인한 뒤 진행해 주세요. (plan 이름은
  Render 요금제가 바뀌면 달라질 수 있어서, Blueprint 적용이 안 되면 대시보드에서
  Postgres를 직접 만들고 이름을 맞추거나 render.yaml의 `plan` 값을 최신 플랜 이름으로
  바꿔주세요.)
- **로컬 실행**: 로컬 Postgres를 하나 띄우고, 실행 전에 환경변수를 설정해 주세요.
  ```bash
  export DATABASE_URL="postgresql://사용자명:비밀번호@localhost:5432/데이터베이스명"
  streamlit run app.py
  ```
  테이블(`board_posts`, `board_comments`)은 앱이 처음 실행될 때 자동으로 만들어져요.

## 새 도구를 추가하는 방법

1. `tools/` 폴더 안에 파이썬 파일을 하나 만듭니다. (예: `tools/pdf_watermark.py`)
2. 파일 안에 아래 두 가지를 넣습니다.

   ```python
   TOOL_META = {
       "name": "화면에 보여줄 도구 이름",
       "category": "PDF",  # PDF / Excel / 한글 / NC데이터 / 기타
       "description": "1줄짜리 쉬운 기능 설명",
       "icon": "💧",
   }

   def render():
       ...  # 파일 업로드 → 옵션 선택 → 실행 → 다운로드 순서로 화면 구성
   ```

3. 저장하면 끝입니다! `app.py`를 고칠 필요 없이 사이드바 메뉴에 자동으로
   나타나요. 여러 도구가 함께 쓰는 화면 도우미 함수는 `common.py`에 있으니
   참고하세요. (`tool_header`, `friendly_errors`, `download_result`,
   `step_caption`, `parse_page_ranges`)
